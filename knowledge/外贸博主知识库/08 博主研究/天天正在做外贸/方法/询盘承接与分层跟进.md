# 询盘承接与分层跟进

先把询盘接住，再判断怎样推进。社媒播放不是订单；回复入口分散、等待工厂确认时没有记录，都可能让有意向的客户失去后续。

## 本库行动清单

以下步骤为本库据主题新写，不是作者逐字教程。

1. 把各平台的询盘入口列全，明确每天由谁检查未读、未回和待确认事项。
2. 给每位客户记录产品、数量、已发资料、当前阶段、待办及下一次联系时间。
3. 把索取目录、常见问题等标准任务与具体报价、交期承诺分开；后者交由有授权的人核对。
4. 根据客户反馈更新阶段标签和备注；看有效回复、试单与订单变化，不只看播放量。

## 作者做法与使用条件

视频推荐SaleSmartly，并演示工作流和AI功能；本库没有独立测试其效果，也没有替用户绑定账号。自动回复要使用准确资料，并设置人工接手范围。
