## 各国特色美食与文化活动

下列是可聊话题，不能代填成客户的个人爱好。请本人推荐一道菜、一首歌或一种休闲活动，再真实反馈。

### 哈萨克斯坦

[详细条目与来源](KZ.md)

**美食：**

- Бешбармақ / Beshbarmak：肉与面片类菜肴。
- Қазы / Kazy：马肉类传统食品，具体加工与供应方式有差异。
- Қуырдақ / Kuyrdak：炒制或煎烤肉类菜肴，配料随做法变化。
- Бауырсақ / Baursak：油炸面点，可配茶或其他食物。
- Ірімшік / Irimshik：传统乳制食品。
- Құрт / Kurt：乳制食品，在传统食物介绍中常出现。
- Қымыз / Kumys：发酵乳饮品。
- Шұбат / Shubat：传统发酵乳饮品之一。

**音乐、歌舞及相关活动：**

- 冬不拉Kuy：冬不拉Kuy具有器乐演奏传统。
- Aitys即兴对唱：Aitys涉及即兴诗歌和表演者之间的交流。
- Orteke表演：Orteke结合舞蹈、木偶和音乐，见于相关文化遗产资料。
- Kures运动话题：Kures见于哈萨克文化遗产介绍。

### 乌兹别克斯坦

[详细条目与来源](UZ.md)

**美食：**

- Palov / Osh：米饭、肉和蔬菜等组成的地方菜，存在地区版本。
- Somsa / Samsa：烤制馅面点，馅料及做法随地区和季节变化。
- Lagman：面条类地方菜。
- Manti：蒸制包馅面食。
- Shashlik / Kabob：串烤肉类及其不同版本。
- Non / Patyr：面饼及其地方做法。
- Shurpa：肉和蔬菜等组成的汤类。
- Nonushta早餐：传统早餐介绍涉及面饼、乳制品、茶及水果等。

**音乐、歌舞及相关活动：**

- Lazgi舞蹈：Lazgi是与花剌子模文化相关的舞蹈传统。
- Shashmaqom音乐：Shashmaqom结合声乐、器乐和诗歌等内容。
- Katta Ashula：Katta Ashula与费尔干纳谷地等地区的歌唱传统相关。

## 个人作息记录字段

|字段|未知时怎样处理|

|当前所在地与时区|先确认，不能只按国籍或公司总部|
|工作日与联系窗口|用保守候选，明确尚未确认|
